# Notes 📚

Mis apuntes personales de inglés y software, escritos en Markdown con Obsidian y versionados con Git.

## Contenido

- [english/](english/): apuntes de inglés tomados del canal de YouTube Francisco Ochoa Inglés Fácil, entre otros canales, además de tarjetas de Anki y ejercicios de listening.
- [software/](software/): apuntes de la Escuela de DW de Platzi, Devtalles y YouTube, además de otros temas (Git, Linux, Django, Excel) y proyectos.

## Cómo usarlo

1. Clona el repositorio: `git clone git@github.com:aleroses/notes.git`
2. Abre la carpeta `notes/` en Obsidian con "Abrir carpeta como bóveda" para navegar ambos temas en una sola bóveda.
3. Modifica y mejora los apuntes según tu criterio: son solo una base para crear los tuyos. ✨
